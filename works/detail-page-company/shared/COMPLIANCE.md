# 화장품 광고 심의 가드레일 (필수 준수)

> 근거: 화장품법 제13조·제14조, 식약처 「화장품 표시·광고 관리 지침」(2024.5 개정),
> 대한화장품협회 「화장품 광고자문 기준 및 해설서 2025」
> 출처 문서: `biomoa/글루타치온팩_분석보고서.md` §7.3
>
> **이 문서는 상세페이지 작업의 모든 단계에서 최우선 제약이다.**
> 카피가 아무리 좋아도 이 규칙을 어기면 폐기한다. 위반 시 1년 이하 징역 또는 1천만 원 이하 벌금.

---

## 0. 판단 순서

문구를 쓸 때마다 이 순서로 확인한다.

1. 이 표현이 **금지 목록(§2)**에 있는가 → 있으면 즉시 폐기
2. 이 표현이 **허용 목록(§1)**에 있는가 → 있으면 사용 가능
3. 둘 다 아니면 → **금지로 취급하고** `product_brief.uncertain_claims` 에 올린다
4. 개별 문구가 통과해도 **§3 금지 조합**을 다시 확인한다

애매하면 쓰지 않는다. 판단을 미루지 말고 보수적으로 결정한다.

## 1. 허용 표현 (일반화장품)

대한화장품협회 해설서에 명시적으로 허용된 문구다. 그대로 쓰거나 최소한으로 변형한다.

- "피부를 밝고 화사하게" / "맑게 케어" / "피부에 투명함을 선사"
- "윤기 있고 매끄러운 피부 톤" / "고유한 빛을 북돋아준다"
- **광채 · 윤기 · 생기 · 피부결 정돈 · 매끈한 피부 · 보습**
- "피부 노폐물·모공 속 노폐물 제거" / "각질·피지 케어" / "피부 턴오버 주기 관리"
- 성분·함량의 **사실 언급까지만**: "글루타치온 700ppm 함유", "300달톤 초저분자 콜라겐"
- 실증자료를 보유한 경우에만: **"인체적용시험 완료"** (※ '임상'이 아니라 '인체적용시험'으로 표기)

## 2. 금지 표현

### 2.1 기능성 미인증 상태에서 절대 불가

**이 제품은 기능성화장품 심사·보고 여부가 확인되지 않았다. 미인증 전제로 작업한다.**

- **"미백" "화이트닝" "브라이트닝(효능 맥락)" "잡티/기미 완화" "다크스팟 케어"** — 한글·영문 모두 불가
- **"글루타치온이 미백에 도움"** — 원료 효능 설명 형식도 불가.
  글루타치온은 식약처 **미백 기능성 고시원료 9종에 포함되지 않는다.**
- **"주름개선" "리프팅"** — 주름개선 기능성 미인증 시 불가
- "피부 재생" "세포 재생"

### 2.2 제형·작용 관련 금지

- **"진피층까지 침투" "피부 깊숙이 전달" "속에서부터" "속광"** — 심층 작용 암시.
  2025년 식약처 집중 단속 유형이다. `속광`은 내부 연출 무드 용어로만 쓰고 **자막·카피에 절대 노출 금지**
- "디톡스" "독소 배출" / "모공 축소" / "여드름·트러블 개선"

### 2.3 의료·비교 관련 금지

- **의료 시술 비교·대체 표현** — "시술 없이", "시술 1회 가격", 백옥주사 연상 카피
- 병원·의사 추천 연출 / "식약처 인증" 표현
- "즉시" "최고" "1위"(근거 미확보 시) 등 절대적 표현

### 2.4 표시·가격 관련 금지

- 실거래 이력이 확인되지 않은 정가 대비 **할인율 표기**
  (이 제품은 주요 온라인 채널이 모두 17,900원 동일가 → "49% 할인" 표기는 부당 가격표시 리스크)
- 집계 주체·기간이 특정되지 않은 **"1위"**

## 3. 금지 조합 — 개별 문구가 합법이어도 위반

**가장 중요하고 가장 놓치기 쉬운 규칙이다.**
광고는 개별 문구가 아니라 **전체 인상(overall impression)**으로 심의된다.

### 3.1 명도 변화 서사 금지

> ❌ "칙칙한 피부(비포) → 환해진 피부(애프터)"

문제 제기를 *칙칙함·어두움*으로 하고 결말을 *환해짐·밝아짐*으로 맺으면,
개별 문장이 전부 허용 목록 안에 있어도 **전체 인상이 미백 표방**으로 판정된다.

**올바른 설계:**
- 문제 제기 → **푸석함 · 윤기 없음 · 생기 없음**
- 변화·결말 → **광채 · 윤기 · 매끈함 · 피부결**
- 비포/애프터 이미지 → **명도 차이가 아니라 윤기 차이**로. 밝기 보정 금지

### 3.2 성분 + 밝아짐 조합 금지

> ❌ 글루타치온 성분 강조 + 밝아진 피부 비포/애프터

소비자가 글루타치온을 이미 '미백'으로 학습했기 때문에, 이 조합은 단독 문구보다 **더 위험하다.**
성분 수치를 말할 때는 광채·윤기 맥락으로만 연결한다.

### 3.3 섹션 배치로도 조합이 생긴다

상세페이지는 영상보다 텍스트가 많아 **위반 표면이 넓다.**
허용 문구라도 아래처럼 배치되면 조합 위반이 된다.

- "색소침착 고민" 컷 바로 뒤에 글루타치온 성분 컷
- 고객 후기에 "하얘졌다", "톤이 밝아졌다"는 내용을 인용
- FAQ에 "미백 효과 있나요?"라는 질문을 넣는 것 자체

**후기·FAQ·각주·표 안의 작은 글씨까지 전부 심의 대상이다.**

> 우리 산출물은 세로로 긴 이미지다(`CANVAS.md`). 그래서 심의 대상은
> **이미지 안에 픽셀로 찍힌 모든 글자**다. `alt` 텍스트는 존재하지 않는다.
> 그리고 심의는 슬라이스 한 장이 아니라 **이어서 스크롤한 전체 인상**으로 이루어진다 —
> 컷 A와 컷 B가 각각 합법이어도 붙여 놓으면 위반이 될 수 있다.

## 4. 이 제품(글루타치온 콜라겐 필오프팩) 고유 제약

| 항목 | 상태 | 작업 규칙 |
|---|---|---|
| 기능성화장품 심사 | **미확인** | 미인증 전제. 미백·주름개선 계열 전면 금지 |
| 인체적용시험 보고서 | **원본 미확보** | 구체 수치를 카피로 쓰지 않는다. "1회 사용 직후 광채" 류 즉시성 카피도 시험 범위 확인 전까지 불가 |
| 판매 실적 150만 개 | 보도 근거 있음 | 사용 가능하되 **집계 기준·기간 각주 필수** |
| '홈쇼핑 팩 1위' | 집계 주체 미확인 | **사용 금지** |
| 올리브영 4.9점(3,304건) | 확인 가능 | 사용 가능. 시점 표기 |
| 정가 35,000원 | 실거래 이력 미확인 | 할인율 표기 금지. 절대가·묶음 혜택으로 |
| '김청팩' 명칭 | 명칭권 없음 | **사용 금지** |

**색소침착은 이 제품 타겟(40·50대 여성)의 피부 고민 1위(68.9%)지만, 광고로 소구할 수 없다.**
합법 소구축은 **광채 · 윤기 · 탄력 · 피부결** 뿐이다. 이 긴장이 이 제품 카피의 핵심 난이도다.

## 5. 필수 고지사항

- 비포/애프터를 쓰면 **"개인차가 있을 수 있습니다"** 고지
- 판매 실적 카피에는 **집계 기준·기간 각주**
- 화장품 필수 표시사항: 전성분, 제조업자·책임판매업자, 사용기한, 사용 시 주의사항, 용량
- 실증자료는 요청 시 **15일 내 제출 의무**(화장품법 제14조).
  실증자료가 없는 표현은 애초에 쓰지 않는다.

## 6. 단계별 책임

| 단계 | 규제 관련 책임 |
|---|---|
| Analyst | 기능성 인증 여부·실증자료 보유 현황을 확인해 `forbidden_claims`, `uncertain_claims` 를 채운다. 근거 없는 것은 전부 금지 목록으로 |
| Strategist | 합법 소구축(광채·윤기·탄력·피부결)만으로 설득 흐름을 짠다. 색소침착·미백을 문제 제기에 넣지 않는다. **컷 순서가 §3.3 조합을 만들지 않는지 확정 전에 확인한다** |
| Designer | §1 허용 표현으로만 카피를 쓴다. 저장 전 §3 조합 검사를 스스로 수행하고 결과를 코멘트에 남긴다. **생성·보정한 이미지에도 같은 검사를 한다** — 라벨 원본 일치, 피부 밝기 무보정, 이미지 내 텍스트 없음 |
| Builder | 고지사항·각주가 **캡처 결과 이미지 안에 실제로 보이게** 조판한다. 접거나 링크로 빼면 고지하지 않은 것이다. 각주 24px 미만으로 줄이지 않는다 |
| QA | 문장 단위 검사 + **전체 서사 판정**. 슬라이스를 이어서 보며 판정한다. `regulatory` 카테고리 이슈는 전부 `blocker` 로 분류한다 |

## 7. 확신이 없을 때

**쓰지 않는다.** 그리고 `uncertain_claims` 에 올려 사람이 판단하게 한다.

제작 전 **대한화장품협회 광고자문**을 받으면 적발 전 시정 기회가 부여된다.
자문 질의에는 ① 전체 인상 판정 ② 비포/애프터 연출·보정 허용 범위를 반드시 포함한다.
