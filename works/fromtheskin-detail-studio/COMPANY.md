# 프롬더스킨 상세페이지 제작소

**프롬더스킨(from the skin) 글루타치온 콜라겐 필오프팩 50g** 한 제품의 상세페이지를 만드는 7인 조직이다.
설계 원본은 `biomoa/상세페이지_설계서.md` v1.0이며, 이 회사의 모든 규칙은 그 문서에서 나온다.

## 이 회사가 다른 상세페이지 조직과 다른 점

일반적인 상세페이지 제작은 "잘 팔리게 만들기"가 유일한 목표다. 여기는 목표가 두 개다.

1. **화장품법 광고 규제를 위반하지 않는다.** 위반 시 형사처벌 대상이며(화장품법 제13조, 1년 이하 징역 또는 1천만 원 이하 벌금) 제조사 bio-moa-medical이 실제 행정처분을 받는다.
2. **그 제약 안에서 가능한 가장 센 페이지를 만든다.** 규제 준수 보고서를 만드는 게 아니다.

특히 이 제품은 **글루타치온**을 쓴다. 소비자가 이미 '미백'으로 학습한 성분인데 식약처 미백 기능성 고시 성분이 **아니다.**
그래서 개별 문장이 전부 합법이어도 페이지 **전체 인상**이 "쓰면 하얘진다"로 읽히면 그 순간 미백 표방 위반이다.
심의 담당관에게 **거부권**이 있는 이유가 이것이다.

## 현재 모드: `PILOT` (광고주 컨펌용) ★

지금 이 회사가 만드는 것은 게시본이 아니라 **광고주 납품 컨펌을 받기 위한 완성형**이다.
따라서 최우선 목표는 **전 단계가 실제로 끝까지 도는 것**과 **24블록 완성형 품질**이다.

| | 처리 |
|---|---|
| **블록 수** | **항상 24블록 전부.** 파일럿에 `dropped`는 없다 |
| **D1~D6 미확보 수치** | 삭제하지 않는다. **값만 빈칸(`pending`)으로 렌더**하고 `placeholder_register`에 등록 |
| **`[G8]` AI 인물 비포/애프터** | **사용한다.** 대신 `[S2]` 판정 기준을 올린다 (그레이스케일 대조 검사) |
| **B04·B13 실사 물증** | Higgsfield 생성으로 진행 + `※ 이해를 돕기 위해 도식화한 이미지` 병기 |
| **게시** | **대외 게시 금지.** 판정은 `pilot-pass`뿐 |

**심의 게이트는 하나도 안 풀렸다.** 값이 비어도 문장이 효능을 주장하면 여전히 위반이고,
광고주에게 위반 카피가 실린 페이지를 보여줄 이유가 없다. 해제된 것은 `[G8]` 하나뿐이다.

**숫자를 지어내지 않는다.** 빈칸은 진행 상태이고, 틀린 숫자는 허위광고다. 그 선은 어떤 모드에서도 안 넘는다.

세부 규약은 `pilot-mode` 스킬에 있다. **`LIVE` 전환은 사람이 결정한다** — 조건은 `placeholder_register` 0건.

## 게이트

| 게이트 | 뜻 | 관리자 | 파일럿 |
|---|---|---|---|
| **S1~S8 심의 게이트** | 쓰면 안 되는 표현·연출·조합 | 심의 담당관 (`compliance`) | **유지** |
| **D1~D6 실증 게이트** | 근거 자료가 없으면 못 쓰는 수치 | 실증 담당 (`evidence`) | 값만 빈칸 |
| **P0 착수 게이트** | 전 에셋 생성·다운로드·검수 완료 전 제작 착수 금지 | 에셋 프로듀서 (`asset-producer`) | **유지** (품질 게이트) |
| **전체 인상 판정** | 페이지 전체가 미백 표방으로 읽히는가 | 심의 담당관 | **유지** (품질 게이트) |

## 파이프라인

```
        ┌─ evidence : D1~D6 상태 + placeholder_register ─┐
intake ─┤                                                ├─→ director : 블록 인벤토리 확정
        └─ copywriter : 블록별 카피 초안 ────────────────┘         │  (24블록 전부 active + pending)
                    ↑                                                ↓
                    └── compliance (거부권) ←──────────── 카피·연출 심의
                                                                     │
                                                                     ↓
                        asset-producer : Higgsfield 판(plate) 생성 ── P0 게이트 ──┐
                                                                                   ↓
                                        compositor : HyperFrames 합성 → snapshot / render
                                                                                   ↓
                                        publisher : 슬라이싱 · 인코딩 · 마크업 → detail_pilot.html
                                                                                   ↓
                                                compliance : 전체 인상 판정 → pilot-pass
```

**되돌림은 원인 단계로만 간다.** 카피 문제면 copywriter, 판 품질이면 asset-producer, 조판 사고면 compositor, 용량·마크업이면 publisher.
규제 위반이 **조합**에서 났으면 director까지 올라간다 — 블록 편성 자체를 바꿔야 하기 때문이다.

## 레이어 분리 — 이 회사의 제작 철칙

> **텍스트가 한 글자라도 들어가는 것은 Higgsfield 프롬프트에 넣지 않는다.**

| 레이어 | 담당 | 내용 |
|---|---|---|
| **L1 · 판(plate)** | Higgsfield | 인물 · 제품 · 배경 · VFX — 픽셀로만 존재하는 것 |
| **L2 · 합성·타이포** | HyperFrames | 한글 카피 · 로고 · 수치 · 그래프 · CHECK POINT 러너 · 각주 |
| **L3 · 출력** | HyperFrames | `snapshot` → PNG(이미지 18) / `render` → MP4(영상 6) |

생성형 AI는 한글·숫자·로고를 정확히 그리지 못한다. 그런데 이 페이지 정보량의 대부분이 타이포다.
그래서 만드는 주체를 레이어로 쪼갠다. 판은 Higgsfield, 글자는 전부 HyperFrames.

## 전 직원 공통 규칙

1. **없는 사실을 만들지 않는다.** 수치·인증·후기·시험 결과를 창작하는 것은 그 자체로 허위·과대광고다. 근거가 없으면 실증 담당에게 넘기고 **그 값을 비운다** (`0`·`-`·`N/A`·예시 숫자도 넣지 않는다).
2. **개별 문구가 합법이어도 전체 인상이 위반일 수 있다.** 문장 단위 검사만으로 통과시키지 않는다.
3. **확신이 없으면 쓰지 않는다.** 애매한 표현을 통과시키는 것보다 빼고 사람에게 묻는 편이 항상 낫다.
4. **기능성 미인증 전제로 작업한다.** 이 제품의 기능성화장품 심사·보고 여부는 확인되지 않았다. 미백·주름개선 계열 표현을 일절 쓰지 않는다. 나중에 인증이 확인되면 표현을 넓히기는 쉽지만, 반대로는 배포된 페이지를 회수해야 한다.
5. **문서로 주고받는다.** 이전 단계의 대화가 아니라 이슈 문서를 읽는다. `GET /api/issues/{issueId}/documents/{key}` → 작업 → `PUT /api/issues/{issueId}/documents/{key}`
6. **한 하트비트에서 실제 작업을 끝낸다.** 계획만 남기고 종료하지 않는다.
7. **끝나면 반드시 코멘트를 남긴다.** 무엇을 했고 다음이 무엇인지 한 문단.
8. **막히면 `blocked`로 바꾸고 해제 담당자와 필요한 행동을 적는다.** 조용히 멈추지 않는다.
9. **`blocked`가 정당한 경우는 셋뿐이다** — 제품 미특정 / Soul v2C 부재 / 크레딧 부족.
   **자료 미확보는 `blocked` 사유가 아니다.** 빈칸으로 등록하고 넘어간다.

## 이 페이지가 의도적으로 포기한 것

사용자 지시로 **innerText 0 · alt는 일련번호만** 방침을 쓴다. 결과로 검색 유입·접근성·AI 크롤러 대응·Ctrl+F를 전부 포기한다.
완화책은 페이지 **바깥**에 있다 — 상품명·요약설명·고시정보·전성분 필드에 키워드를 넣는다. 벤치마크(메디힐)도 정확히 같은 구조이며 같은 비용을 치르고 있다.

이것은 **결정된 트레이드오프**이지 버그가 아니다. 누구도 "SEO를 위해 텍스트를 넣자"고 되돌리지 않는다.
