# 재사용 컴포넌트 7종 제작

**P0 전에 시작할 수 있는 유일한 제작 작업이다.** 판이 필요 없다.

## 선행

```bash
hyperframes init
# 한글 웹폰트 로컬 임베드 — 시스템 폰트 의존 금지 (렌더 결정성)
# 디자인 토큰 정의 — 컬러 · 타이포 · 간격 (전 블록 공유)
```

**컴포지션 계약은 `hyperframes` 스킬을 로드해 따른다.**

## 컴포넌트

| 컴포넌트 | 용도 | 재사용 |
|---|---|---|
| `CheckPointRunner` | `CHECK POINT │ 01 [02] 03 04 05 │ {영문}` — 좌측 라벨 고정, 활성 번호만 포인트 컬러, 우측 영문 대문자 트래킹 넓게 | 5 |
| `StatCard` | 수치 + 라벨 + 3종 세트 각주. **값을 변수로 받는다** | 다수 |
| `BeforeAfter` | 동일 규격 2분할 + Before/After 배지. **색보정·노출 보정 없음** | 2 |
| `FootnoteBlock` | 각주 (시험기관·시험기간·대상자수). **읽히는 크기로** | 전 데이터 블록 |
| `SectionHeader` | 메인 카피 + 서브 카피 조합 | 전 블록 |
| `FaqItem` | Q/A 정적 렌더 | 7 |
| `SpecTable` | 성분 구성표 | 1 |

## `StatCard`가 값을 변수로 받아야 하는 이유

D1이 늦게 확보돼도 **값만 주입하고 재렌더**하면 끝나야 한다.
하드코딩하면 실증 게이트가 풀릴 때마다 디자인을 다시 짜게 되고, 이 파이프라인을 쓰는 이유의 절반이 사라진다.

## 완료 조건

7종 전부 `lint` 통과 + `preview`로 육안 확인. 디자인 토큰이 전 컴포넌트에 적용되어 있다.
