# 전체 인상 판정

광고주 컨펌 발송 직전 마지막 관문이다. **문서를 읽고 판정하지 않는다. 렌더된 결과물을 실제로 본다.**

파일럿이라고 기준을 낮추지 않는다. **컨펌 미팅에서 미백 표방으로 읽히는 페이지를 내놓을 수 없다.**

## 절차

1. `page_markup`이 참조하는 슬라이스와 영상을 **순서대로 전부 연다.**
2. B01부터 B24까지 **스크롤하듯 훑는다.** 블록 단위로 뜯어보지 않는다 — 소비자는 그렇게 보지 않는다.
3. 다 보고 나서 **남는 한 문장**을 적는다.

| 남는 문장 | 판정 |
|---|---|
| 「각질을 떼어내서 피부결을 정돈하는 팩이다」 | **`pilot-pass`** |
| 「글루타치온 함량을 공개하는 제품이다」 | **`pilot-pass`** |
| 「이거 쓰면 하얘진다」 | **`pilot-fail` — 발송 중단** |
| 「푸석하던 피부가 환해진다」 | **`pilot-fail` — 발송 중단** |

## 함께 확인

- [ ] 서사가 **푸석함 → 광채·매끈함**인가. **칙칙함 → 환해짐**이 아닌가
- [ ] B06(글루타치온)과 B10(비포/애프터)이 시각적으로 이어져 보이지 않는가
- [ ] **B10 비포/애프터를 그레이스케일로 변환해 나란히 놨을 때 밝기 차이가 없는가** — `[G8]` 해제로 AI 인물 페어를 쓰므로 여기가 최대 위험 지점이다
- [ ] B10 두 컷이 동일 인물·동일 조명·동일 각도인가
- [ ] 피부 도해가 표피·각질층을 넘지 않는가
- [ ] **값이 들어간** 수치에 3종 세트 각주가 **읽히는 크기로** 붙어 있는가

- [ ] 빈칸 각주가 `※ 실증자료 확보 후 확정`인가

- [ ] 나이·연령대 언급이 없는가

## 완료 조건

`compliance_report`에 `overall_impression`(`pilot-pass` / `pilot-fail`)과 `publishable: false`를 기록한다.

`pilot-pass`면 총괄 디렉터에게 **컨펌 발송 승인**을 넘긴다. 발송 시 `placeholder_register`를 항상 함께 보낸다.
`pilot-fail`이면 **어느 블록의 무엇이 그 인상을 만들었는지** 특정해서 되돌린다 — 조합 문제면 총괄 디렉터에게 간다.

**`pass`(게시 승인)는 파일럿에서 나오지 않는다.** `LIVE` 전환은 `placeholder_register` 0건 + 협회 자문 회신 후 사람이 결정한다.
