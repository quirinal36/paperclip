# 판(plate) 생성 및 P0 통과

`block_inventory`가 요구하는 판을 전부 만들고, 검수를 통과시키고, **P0 통과를 선언한다.**

## 대상

| 계열 | 항목 | 비고 |
|---|---|---|
| **M** 모델 컷 | M01~M11 | Soul v2C + 의상 고정 문자열 |
| **P** 제품 컷 | P01~P08 | P03·P07은 실물 대조 검수 필수 |
| **F** VFX | F01~F06 | F02는 영상 5초 |
| **R** 실사 | R01~R04 | 사람의 결정에 따름 (권고: B04·B13은 실사) |

작업량이 크므로 **자식 이슈로 쪼개 병렬 진행한다.** Seedance 동시 실행 ~6개 제한을 지킨다.

## 전 프롬프트 공통

```
no text, no letters, no logo, no watermark
```

인물 컷에는 의상 고정 문자열을 **한 글자도 바꾸지 않고** 삽입한다.

## 주의

- **`[AI-1]`** M04·M05 — 제품 라벨 왜곡. 실사 레퍼런스 업로드 또는 합성 후처리 전제
- **`[G8]` 해제** M02·M03 — **B10에 투입한다.** 대신 동일 시드 계열 + 윤기만 변경, 밝기·톤 형용사 금지, 생성 후 그레이스케일 대조 필수
- **P03** 스파출라 — `PERMANENTLY ATTACHED` 강제. 안 하면 분리형으로 그려진다
- **P07** 전성분 표기면 — 실사 스캔 권장

## 검수 7항목 — 전 컷을 나란히 놓고 판정

1. 인물 동일성 2. 의상 일관성 3. 컬러 베이스 4. 광 표현 5. 심의 `[S2]` 6. AI 아티팩트 7. 해상도

**한 장씩 보면 1·2·3번은 절대 안 걸린다.** 반드시 전 컷을 한 화면에 놓는다.
실패한 컷은 `_rejected/`로 옮기고 재생성한다.

## 완료 조건 — P0 통과 선언

- [ ] 전 항목 생성 완료 (잡 성공 · 결과 URL 확보)
- [ ] `assets/` 하위에 규약대로 다운로드 완료
- [ ] `_manifest.json`에 ID·잡ID·프롬프트·검수결과 기재
- [ ] 7항목 검수 전량 통과
- [ ] **P0 통과 선언** — `asset_manifest`에 명시

**부분 착수를 허용하지 않는다.** "먼저 되는 블록부터"라는 요청이 오면 거절하고 총괄 디렉터에게 보고한다.
