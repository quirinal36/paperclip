# 빈칸 대장 작성 + D4 확보 병행

**이 태스크는 파이프라인을 막지 않는다.** 자료가 없어도 그대로 다음 단계로 넘긴다.

## 1. `placeholder_register` 작성 (선행 · 필수)

D1~D6 전부 미확보 상태를 전제로, **빈칸으로 나갈 모든 자리**를 등록한다.

```json
{
  "mode": "PILOT",
  "publishable": false,
  "entries": [
    { "id": "PH-01", "block": "B06", "slot": "글루타치온 함량",
      "gate": "D4", "unit": "ppm", "expected_digits": 3,
      "unblock": "성분 시험성적서 확보 → 사람" }
  ],
  "summary": { "pending_values": 0, "advisory_pending": 0, "asset_substitutions": 0 }
}
```

**`expected_digits`를 반드시 적는다.** 컴포지션 엔지니어가 최종 숫자가 차지할 폭 그대로 빈칸을 잡아야
자료가 왔을 때 값만 주입하고 재렌더로 끝난다.

### 등록 대상 (최소)

| 게이트 | 빈칸 자리 |
|---|---|
| D4 | 글루타치온 함량(ppm, 3자리) · 순도(%, 4자리) · 콜라겐 분자량(Da, 3자리) · 콜라겐추출물(ppm) — B01·B06·B07·B08 |
| D1 | B11 인체적용시험 수치 표 전체 · B12·B14·B15 수치 · B20 시험 정보 · B22 사용 빈도 |
| D2 | B01 누적 판매 배지 숫자 · B02 「150만 개」 |
| D3 | B02 리뷰수·평점 (수집 시점 캡처 확보 시 즉시 주입) |
| D5 | B20 인증 씰 — **어떤 인증을 상정한 자리인지 반드시 명시** |
| D6 | B18 적정 사용량 · B22 Q2 |
| G8 | B10 AI 인물 비포/애프터 — `advisory_pending` (협회 자문 미회신 상태로 사용 중) |
| 에셋 | B04·B13 Higgsfield 대체본 — `asset_substitutions` |

> **인증 씰 자리를 조심한다.** 보유하지 않은 인증의 자리를 비워 두면
> 광고주가 "저건 받을 수 있는 거죠?"로 읽는다. 무엇을 상정한 자리인지 등록에 남긴다.

## 2. D4 확보 (병행 · 논블로킹)

| 수치 | 필요한 근거 |
|---|---|
| 글루타치온 700ppm | 원료 또는 완제품 함량 시험성적서 |
| 순도 98.2% | 원료 규격서 / 시험성적서 |
| 콜라겐 300달톤 | 분자량 시험성적서 (캐나다산) |
| 콜라겐추출물 약 70만ppm | 처방전 또는 전성분 표기 근거 |

확인 항목 — **파일이 있다고 확보가 아니다.**

- [ ] 문서의 숫자가 카피의 숫자와 **정확히 일치**하는가 (700 vs 750은 위반)
- [ ] 시험 대상이 **원료**인가 **완제품**인가
- [ ] 발행 기관·발행일이 명시되어 있는가
- [ ] **15일 내 제출 가능한 원본**인가

확보되면 `evidence_ledger` D4를 `확보`로 올리고 `placeholder_register`에서 해당 항목을 제거한 뒤,
컴포지션 엔지니어에게 **값 주입 + 재렌더** 자식 이슈를 만든다. 디자인 재작업은 없다.

## 완료 조건

**`placeholder_register`가 작성되면 이 태스크는 완료다.** D4 확보 여부와 무관하다.

D4를 못 구했다는 이유로 이슈를 `blocked`로 두지 않는다.
`blocked`는 자료가 **틀렸을 때** 쓴다 — 예: 시험성적서 수치가 카피와 불일치.
