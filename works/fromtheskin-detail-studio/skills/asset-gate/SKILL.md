# P0 — 제작 착수 게이트

> **대원칙: 이 상세페이지의 설득력은 이미지와 영상이 만든다.**
> 컨셉·톤앤매너에 부합하는 에셋이 전량 확보되기 전에는 페이지 제작을 시작하지 않는다.

```
① 생성 완료      Higgsfield 잡 성공 · 결과 URL 확보
      ↓
② 로컬 다운로드   assets/ 하위에 규약대로 저장 · _manifest.json 기재
      ↓
③ 검수 통과      아래 7항목 전체 통과
      ↓
   ── P0 통과 선언 ── → HyperFrames 컴포지션 작성 착수
```

## 부분 착수를 금지하는 이유

**톤앤매너 일치는 에셋 전체를 나란히 놓고서만 판정할 수 있다.**

컷 단위로 개별 승인하면 개별로는 다 괜찮은데 모아 놓으면
인물이 다른 사람 같고 화이트 밸런스가 제각각인 페이지가 나온다.
벤치마크(메디힐) 페이지가 27블록 내내 균질하게 읽히는 이유가 바로 이것이다.

"먼저 되는 블록부터 조판하자"는 요청은 **거절한다.**

**P0 전에 할 수 있는 유일한 작업**: 재사용 컴포넌트 7종 제작 (판이 필요 없다).

## 톤앤매너 검수 7항목

| # | 항목 | 판정 기준 |
|---|---|---|
| 1 | **인물 동일성** | 전 모델 컷이 **같은 사람**으로 읽히는가 (Soul v2C 일관성) |
| 2 | **의상 일관성** | 전 컷이 **동일한 새하얀 끈나시**인가 (스트랩 두께·넥라인 포함) |
| 3 | **컬러 베이스** | 화이트·아이보리 기조인가. 컬러 배경·채도 높은 소품이 섞이지 않았는가 |
| 4 | **광 표현** | **번들거리는 하이라이터 광 ✕ / 은은하게 배어나는 윤기 ○.** 글리터·스펙큘러 하이라이트 없는가 |
| 5 | **심의 `[S2]`** | 비포/애프터가 **명도 차이**로 읽히지 않는가. 질감·윤기 차이인가 |
| 6 | **AI 아티팩트** | 손가락 개수·관절, **제품 라벨 텍스트**, 스파출라 구조 왜곡 없는가 |
| 7 | **해상도** | 이미지 폭 2040px 이상 / 영상 폭 1020px 이상, 업스케일 흔적 없는가 |

**한 항목이라도 실패하면 `_rejected/`로 이동 후 재생성.**
검수 결과는 `_manifest.json`에 잡ID와 함께 기록해 재생성 이력을 남긴다.

검수는 **실제로 이미지를 열어 눈으로 본다.** 프롬프트를 읽고 추정하지 않는다.
1·2·3번은 **전 컷을 한 화면에 나란히 놓고** 판정한다 — 한 장씩 보면 절대 안 걸린다.

## 에셋 ↔ 블록 커버리지

| 블록 | 필요 에셋 | 블록 | 필요 에셋 |
|---|---|---|---|
| B01 | M04 · P01 | B13 | **R02** (또는 F05 확장) |
| B02 | M05 · M10 | B14 | 타이포 |
| B03 | F03 | B15 | M11 |
| B04 | **R01** (또는 F05 확장) | B16 | P03 |
| B05 | P02 | B17 | R03 |
| B06 | F01 · P04 | B18 | M06·M07·M08·M09 · R04 |
| B07 | F02 | B19 | P05 |
| B08 | P04 · P06 · P07 | B20 | 타이포 |
| B09 | M01 · F04 | B21 | M04 · P08 |
| B10 | M02 · M03 `[G8]` · F04 | B22 | 타이포 |
| B11 | — (D1 수치) | B23 | — (고지문) |
| B12 | F06 | B24 | 브랜드 로고 자산 |

판이 하나도 안 걸린 블록은 **B11 · B14 · B20 · B22 · B23** 다섯 개뿐이고 전부 데이터·고지 블록이다.
**19개 블록이 Higgsfield 판에 의존**한다 — P0가 형식이 아니라 실제 병목인 이유.

단, **24블록 전부가 HyperFrames 렌더를 거친다.** 판이 없는 블록도 출력 규격·폰트·컬러 토큰을 공유해야 한다.

## `_manifest.json` 형식

```json
{
  "M01": {
    "file": "model/M01_face-closeup-front_a1b2c3d4.png",
    "job_id": "a1b2c3d4-...",
    "prompt": "...(네거티브 포함 전문)...",
    "created_at": "2026-08-02T10:00:00+09:00",
    "review": { "1": "pass", "2": "pass", "3": "pass",
                "4": "pass", "5": "n/a", "6": "pass", "7": "pass" },
    "verdict": "pass",
    "post_processed": "model/M01_face-closeup-front_a1b2c3d4_v2.png"
  }
}
```

`verdict`가 `pass`가 아닌 항목이 하나라도 있으면 **P0 통과 선언을 할 수 없다.**

## 게이트를 앞당기는 압력에 대해

일정이 밀리면 반드시 "일단 되는 것부터 시작하자"는 제안이 온다.
그 제안은 합리적으로 들리지만, 실제로 벌어지는 일은 **나중에 들어온 판과 톤이 안 맞아 전부 다시 짜는 것**이다.

P0를 앞당기는 결정은 **사람만 할 수 있다.** 에이전트는 게이트를 열지 않는다.
