# 실증자료 게이트

> **화장품법 제14조: 표시·광고 실증자료는 요청 시 15일 내 제출 의무.**
> 제출 못 하면 그 문구는 곧바로 위반이다.

판단 기준은 하나다. **"지금 자료를 요청받으면 15일 안에 낼 수 있는가."**
낼 수 없으면 그 수치는 **값으로** 실리지 않는다. 예외 없다.
다만 **자리까지 없애는 것과 값을 비우는 것은 다르다** — 아래 §파일럿 모드 참조.

## 파일럿 모드에서는 삭제하지 않는다 ★

**현재 회사 모드는 `PILOT`이다.** 아래 §다운그레이드 규칙은 **`LIVE` 모드용**이며 지금은 적용하지 않는다.

| | `LIVE` | **`PILOT` (현재)** |
|---|---|---|
| 미확보 게이트 | 해당 요소·블록 **삭제** | **값만 비운다(`pending`).** 블록 유지 |
| 블록 수 | 최소 18블록까지 축소 | **항상 24블록 전부** |
| 산출 | `evidence_ledger` | `evidence_ledger` **+ `placeholder_register`** |

| ID | 파일럿 처리 |
|---|---|
| **D1** | B11 데이터 표·B12·B14·B15 수치 `pending`. **B20 유지** (인증 씰 자리는 비우고 무엇을 상정했는지 등록) |
| **D2** | B01 배지 자리 유지, 숫자만 `pending`. B02 「150만 개」 슬롯 유지 |
| **D3** | B02 사회적 증거 파트 유지, 리뷰수·평점 `pending` |
| **D4** | `700`/`98.2`/`300`/`70만` 전부 `pending`. **단위와 라벨은 그대로 표시** |
| **D5** | B20 유지, 인증 씰 자리 비움 |
| **D6** | B18 사용량 수치·B22 Q2 답변 `pending` |

세부 규격은 `pilot-mode` 스킬에 있다. **`LIVE` 전환은 사람이 결정한다.**

## D 게이트 현황 (2026-08-01 설계서 기준)

| ID | 자료 | 상태 | 걸린 블록 |
|---|---|---|---|
| **D1** | 인체적용시험 보고서 원본 — 시험기관·기간·대상자수·시험항목, **1회 사용 직후 광채 포함 여부** | ❌ 미확보 (채널별 11~13종으로 표기 불일치) | B11 B12 B14 B15 B20 B22 |
| **D2** | 누적 150만 개 판매 집계 자료 (집계 주체·기간) | ❌ 미확보 | B01 B02 |
| **D3** | 올리브영 평점·리뷰수 캡처 (수집 시점 명기) | ⚠️ 수치는 있으나 시점 캡처 필요 | B02 |
| **D4** | 성분 함량 시험성적서 — 700ppm / 98.2% / 300Da / 콜라겐추출물 70만ppm | ❌ 미확보 | B01 B06 B07 B08 |
| **D5** | 피부 자극 테스트·인증 자료 | ❌ 미확보 | B20 |
| **D6** | 회당 사용량 실측 | ❌ 미확보 | B18 B22 |

**상태 값은 `확보` · `부분` · `미확보` 셋뿐이다. 「확보 예정」은 `미확보`다.**

## D4가 최우선인 이유

D4가 없으면 B01 3수치 배지 · B06 · B07 · B08이 **전부 무력화**된다.
이 페이지가 벤치마크와 다른 유일한 축이 "성분 숫자를 공개한다"인데, 그 축 자체가 사라진다.

**D4 확보를 다른 어떤 작업보다 앞에 둔다** — 단, **확보를 기다리며 파이프라인을 멈추지는 않는다.**
파일럿에서는 그 자리를 빈칸으로 두고 진행하고, 확보 작업은 별도 이슈로 병행한다.

## 다운그레이드 규칙 — `LIVE` 모드 전용 (현재 미적용)

| 상황 | 처리 |
|---|---|
| **D1 미확보** | B11 삭제 → 정성 카피 블록(`1020×800`)으로 대체 (「떼어낸 직후, 손끝에 닿는 매끈함」 + 제형 매크로 컷) / B12·B14·B15는 **수치를 빼고 정성 카피 + 제형 비주얼**로 축소 / **B20 전체 삭제** |
| **D2 미확보** | B01 상단 배지 삭제, B02 「150만 개」 삭제 → 「올리브영 리뷰 3,304건·평점 4.9」만 게시 |
| **D3 미확보** | B02 사회적 증거 파트 전체 삭제 → 고민 말풍선만으로 4초 구성 |
| **D4 미확보** | **치명적** — 페이지의 차별화 축이 사라진다. 최우선 확보 대상 (파일럿에서는 빈칸 처리) |
| **D5 미확보** | B20 전체 삭제 (D1과 함께) |
| **D6 미확보** | B18 '적정 사용량' 컷 보류, B22 Q2 삭제 |

> **근거 없는 인증 표기가 가장 큰 적발 사유다.** D1·D5 둘 다 미확보면 B20은 고민 없이 삭제한다.

## 최소 게시 가능 구성 — `LIVE` 모드 전용 (D4만 확보한 경우)

**18블록 / 약 24,000px** — 데이터가 없어도 필오프 제형 경험 + 성분 수치만으로 페이지가 성립한다.

```
B01(수치만) → B03 → B04 → B05 → B06 → B07 → B08 → B09 → B10
→ B13 → B16 → B17 → B18 → B19 → B21 → B22 → B23 → B24
```

## 3종 세트 — 수치를 쓰는 조건

수치를 **값으로** 게시하려면 아래 셋이 **전부** 있어야 한다. 하나라도 빠지면 그 수치는 `pending`이 된다.

```
시험기관 · 시험기간 · 대상자 n명
```

표기는 **「인체적용시험 완료」**다. **'임상'이라고 쓰지 않는다** — 의약품을 연상시킨다.

## 자료 대조 — 파일이 있다고 확보가 아니다

`확보`로 올리기 전에 **실물을 열어** 아래를 확인한다.

- 시험성적서의 숫자와 카피의 숫자가 **정확히 일치**하는가 (700 vs 750은 위반)
- 시험 대상이 **원료**인가 **완제품**인가 — 원료 시험인데 완제품 함량처럼 읽히면 위반
- 인체적용시험 **항목**에 카피가 주장하는 것이 실제로 있는가 (항목에 '광채'가 없는데 광채 수치를 쓰면 위반)
- 시험기관·기간·대상자수가 문서에 **명시**되어 있는가

`evidence_ledger`에 `확보`를 기록할 때는 **파일 경로와 그 자료가 커버하는 문구 목록**을 함께 적는다.

## 자료가 늦게 와도 페이지는 나간다

실증 게이트의 목적은 게시를 막는 게 아니라 **지금 확보된 것으로 게시 가능한 구성을 확정하는 것**이다.

HyperFrames 파이프라인은 정확히 이걸 위해 설계됐다 — 자료가 뒤늦게 확보되면
**HTML 변수만 교체하고 해당 블록을 재렌더**하면 된다. 디자인 재작업이 없다.

그러니 "D1을 기다리자"는 제안은 하지 않는다. **지금 낼 수 있는 최선을 확정하고, 자료가 오면 그때 활성화한다.**
