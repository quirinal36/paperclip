# 파일럿 모드 (컨펌용)

**현재 이 회사는 `PILOT` 모드로 운영된다.**

목적은 게시가 아니다. **광고주 회사에 납품 컨펌을 받는 것**이다.
따라서 최우선 목표는 두 가지다.

1. **전 단계가 실제로 끝까지 돈다** — 게이트 대기로 파이프라인이 멈추지 않는다
2. **24블록 완성형 품질이 나온다** — 광고주가 완성된 페이지를 본다

## 핵심 규칙 — 삭제하지 않고 비운다

일반 모드에서는 실증 자료가 없으면 그 블록을 **뺐다.** 파일럿 모드에서는 **자리를 남기고 값만 비운다.**

| | 일반 모드 (`LIVE`) | 파일럿 모드 (`PILOT`) |
|---|---|---|
| D게이트 미확보 수치 | 해당 요소·블록 삭제 | **빈칸(`pending`)으로 렌더** |
| 블록 수 | 최소 18블록까지 축소 | **항상 24블록 전부** |
| 게시 | 채널 게시 | **대외 게시 금지 — 컨펌 검토용** |

### 왜 빈칸인가

- **숫자를 지어내면 허위광고다.** 그건 어떤 모드에서도 안 된다.
- **블록을 빼면 광고주가 완성형을 못 본다.** 컨펌 단계에서 "여기는 나중에 채웁니다"는 설명보다 **비어 있는 자리를 실제로 보여주는 편**이 훨씬 정확하다.
- **레이아웃이 최종형으로 확정된다.** 자료가 오면 값만 주입해 재렌더하면 끝이다. 나중에 숫자가 들어올 자리를 미리 잡아 두는 것이 이 파이프라인의 설계 의도 그 자체다.

## 빈칸 렌더 규격

`StatCard`는 `value`가 `null`이면 `pending` 상태로 렌더한다.

| 요소 | pending 상태 처리 |
|---|---|
| 숫자 슬롯 | **예상 자릿수만큼 중성 플레이스홀더 바.** 확정 시 들어올 글자 폭을 그대로 차지한다 |
| 단위 · 라벨 | **그대로 표시** (`ppm`, `%`, `Da`, `달톤` 등) |
| 각주 | `※ 실증자료 확보 후 확정` 으로 대체 |
| 스타일 | 본문 대비 낮은 대비의 중성 톤. **눈에 띄되 오류처럼 보이지 않게** |

**절대 하지 않는 것**

- `0`, `-`, `N/A`, `준비중`, `TBD` 같은 값을 넣지 않는다 — 값처럼 읽힌다
- 예시 숫자를 넣고 "샘플입니다"라고 각주를 달지 않는다 — 캡처되면 그게 주장이 된다
- 빈칸을 숨기려고 레이아웃을 줄이지 않는다 — 최종형 레이아웃이 컨펌 대상이다

## 해제된 게이트

| 게이트 | 파일럿 모드 처리 | 근거 |
|---|---|---|
| **D1~D6 전부** | 블록을 빼지 않는다. 수치만 `pending` | 사용자 지시 |
| **`[G8]` AI 인물 비포/애프터** | **사용한다.** M02·M03을 B10에 투입 | 사용자 지시 |
| **B04·B13 실사 물증** | Higgsfield 생성으로 진행 (F05 확장). `※ 이해를 돕기 위해 도식화한 이미지` 병기 | 실사 촬영 대기로 파이프라인을 멈추지 않는다 |
| **브랜드 로고·패키지 원본 파일** | 없으면 타이포 로고·플레이스홀더로 진행하고 `placeholder_register`에 등록 | 동일 |

**게이트를 해제했다고 위험이 사라진 것은 아니다.** 해제한 항목은 전부 `placeholder_register`에 남고, 게시 전에 반드시 되돌아온다.

## 유지되는 게이트 — 여기는 안 푼다

품질과 직결되거나, 풀면 법적 리스크가 즉시 실현되는 것들이다.

| 게이트 | 유지 이유 |
|---|---|
| **S1 미백 계열 표현 금지** | 카피가 위반이면 파일럿이든 게시본이든 똑같이 위반이다. 광고주에게 위반 카피를 보여줄 이유가 없다 |
| **S2 명도 변화 서사 금지** | **AI 비포/애프터를 쓰기 때문에 오히려 더 엄격히 본다.** 윤기·반사 차이로만. 색보정·노출 보정 금지 |
| **S3 심층 작용 암시 금지** | 동일 |
| **S7 성분 함량 진술까지만** | 동일. 값이 빈칸이어도 문장이 효능을 주장하면 위반이다 |
| **S8 기능성 표현 금지** | 동일 |
| **B23 AI 생성 고지** | **필수. 파일럿에서 더 중요해졌다** — AI 인물을 비포/애프터에 쓰기 때문 |
| **P0 에셋 착수 게이트** | 품질 게이트다. 이걸 풀면 광고주가 보는 것이 톤 안 맞는 페이지가 된다 |
| **전체 인상 판정** | 품질 게이트다. 컨펌 미팅에서 미백 표방으로 읽히는 페이지를 내놓을 수 없다 |

## `placeholder_register` — 파일럿의 핵심 산출물

빈칸으로 남긴 모든 자리의 대장이다. **광고주 컨펌 미팅의 자료로 그대로 쓴다.**

```json
{
  "mode": "PILOT",
  "generated_at": "2026-08-05",
  "publishable": false,
  "entries": [
    { "id": "PH-01", "block": "B06", "slot": "글루타치온 함량",
      "gate": "D4", "unit": "ppm", "expected_digits": 3,
      "unblock": "성분 시험성적서 확보 → evidence 담당" },
    { "id": "PH-02", "block": "B10", "slot": "AI 인물 비포/애프터",
      "gate": "G8", "kind": "advisory",
      "unblock": "대한화장품협회 광고자문 회신 → compliance 담당" }
  ],
  "summary": { "pending_values": 9, "advisory_pending": 1, "asset_substitutions": 2 }
}
```

"이 페이지에서 아직 안 채워진 건 정확히 이 N곳입니다"를 한 장으로 보여줄 수 있어야 한다.
이건 변명 자료가 아니라 **진행 상태의 정확한 지도**다.

## 게시 승인 조건

파일럿 산출물에는 **게시 승인이 나지 않는다.** 나오는 것은 `pilot-pass`뿐이다.

| 판정 | 뜻 |
|---|---|
| `pilot-pass` | 광고주 컨펌용으로 내보내도 좋다. **대외 게시 불가** |
| `pilot-fail` | 컨펌용으로도 못 내보낸다 (심의 위반 카피, 톤 붕괴, 렌더 사고) |

`LIVE` 승인으로 넘어가려면 **`placeholder_register`의 항목이 0건**이어야 한다.
즉 D1~D6 확보 + 협회 자문 회신 + (선택) 실사 물증 확보가 전부 끝나야 한다.

## 산출물 표시

파일럿 산출물은 **파일명과 문서로** 구분한다. 렌더 이미지 안에 워터마크를 넣지 않는다 — 광고주가 보는 것은 최종 품질이어야 하기 때문이다.

- 출력 디렉터리: `out/pilot/`
- 마크업 파일: `detail_pilot.html`
- `page_markup.publishable: false` 명시
- 전달 시 `placeholder_register`를 **항상 함께** 보낸다

## 모드 전환

`LIVE`로 전환하는 것은 **사람의 결정**이다. 에이전트가 스스로 모드를 바꾸지 않는다.
전환 조건은 위 §게시 승인 조건 하나뿐이며, 전환 시 `evidence-gate` 스킬의 일반 다운그레이드 규칙이 다시 살아난다.
